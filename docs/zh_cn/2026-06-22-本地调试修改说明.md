# 2026-06-22 本地调试修改说明

本文档记录本次围绕 `MBCCtools` 本地联调做的资源与流程调整，便于后续继续排查。

## 主要修改

### 1. 资源加载与任务入口

- `interface.json`
  - 资源路径从 `"{PROJECT_DIR}/resource/..."` 改为相对路径 `resource/...`，避免打包目录下资源加载失败。
  - 新增任务 `退出游戏`。
  - `每日/密令奖励` 新增可选项 `等级奖励`，默认值为 `不领取等级奖励`。

### 2. 启动与通用等待时间

- 调整了多处 `post_delay` / `post_wait_freezes`，整体缩短等待时间，减少无意义停留。
- 相关文件包含：
  - `resource/base/pipeline/启动.json`
  - `resource/base/pipeline/友情点.json`
  - `resource/base/pipeline/体力.json`
  - `resource/base/pipeline/密盟.json`
  - `resource/base/pipeline/派遣.json`
  - `resource/base/pipeline/采购办.json`
  - `resource/base/pipeline/邮箱.json`
  - 对应 `bilibili` / `global` 同名流程

### 3. 监管奖励

- 调整 `开始按钮` 的识别区域与点击点。
- 调整 `跳过` 的 OCR 区域与点击区域。
- 修改流程顺序为：
  - 先点击 `开始按钮`
  - 再识别 `跳过`
  - `检查选项` 只在 `跳过` 之后参与
- 当 `下一位` 不存在时，直接回 `主菜单`，不再把“没有下一位”当错误。

### 4. 破碎防线

- `base` 版入口定位从原来的“左滑到尽头/右划”调整为更接近 `global` 的中段定位方案：
  - `内海-推进到中段`
  - `内海-中段微调向右`
  - `内海-中段微调向左`
- 删除中间“确认奖励页后再继续”的旧思路，改为：
  - 进入破碎防线后直接识别左下角 `黄点.png`
  - 识别到黄点则点击左下角奖励按钮
  - 未识别到黄点时，先判断当前是否已经在破碎防线页
  - 若已经在破碎防线页，则判定为奖励已领取完毕，返回主菜单并结束任务
  - 若不在破碎防线页，则继续重试入口
- 入口失败兜底调整为最多 3 次，再走失败收口。

### 5. 浊暗之阱

- `base` 版去掉了对 `内海右箭头` 的依赖。
- 导航链改为更接近 `global`：
  - `浊暗之阱入口`
  - `[JumpBack]数据间隙`
  - `[JumpBack]无尽梦魇`
- 同时补充简繁 OCR 兼容词，并缩短若干等待时间。

## 新增文件

- `resource/base/pipeline/退出游戏.json`
- `resource/bilibili/pipeline/退出游戏.json`
- `resource/global/pipeline/退出游戏.json`
