# UP 池与头像资源维护说明

本项目的以下三项增强能力采用**离线配置 + 零报错回退 + 零维护公式**设计，后续版本更新只需维护单一 JSON 文件即可：

---

## 1. UP 不歪率词表（`resource/base/gacha/up_banners.json`）

手机端与 PC 端共用同一份配置：`resource/base/gacha/up_banners.json`（打包进 APK `pi.zip` 与桌面资源目录）。

### 格式说明
```json
{
  "version": 1,
  "updated_at": "2026-11-25",
  "standard_pools": ["混沌都市", "常规追踪"],
  "banners": {
    "诸道无我": ["承霄"],
    "荒穹孤冕": ["荒噬·伊琳娜"]
  }
}
```

### 日常维护规则
1. **每次新活动 / 限定 / 复刻卡池上线**：在 `banners` 中追加 `"卡池名称": ["UP 狂级角色名"]`。
   - 匹配时会自动忽略空格及 `· . • - — _` 等分隔符，并支持卡池名包含关系（如「光影留痕·黛伦」也可命中 `"光影留痕"`）。
   - 多 UP / 自选定向池直接在数组里列出多个角色名，如 `["角色A", "角色B"]`。
2. **保护策略（宁缺勿错）**：
   - 命中 `standard_pools` 或追踪类型为 `常驻` 的记录，**不计入**不歪率分母，也不标注 UP/歪。
   - **未录入的新卡池**会直接跳过（不误判为「歪」），保证历史数据与旧档案安全。
   - **小保底不歪率（50/50 口径）**：在同一个池子类型下按时间先后追踪保底链，`歪` 之后的下一发 UP 狂会自动标为 `大保底` 并**剔除出**小保底不歪率的分子和分母，避免大保底拉高不歪率。

## 2. 禁闭者头像墙与战报长图（可选配置）

- 目录：`resource/base/image/avatars/`
- 命名：`<角色名>.webp` 或 `<角色名>.png`（推荐 `96×96` 正方形裁剪图）。
- **免维护回退**：若目录不存在或某个角色缺少图片，手机端与 PC 端列表、抽卡战报长图会自动无缝回退为带稀有度配色的**单字徽章卡片**，不会报错或显示裂图。

---

## 3. Lv90 养成资源通用估算（零维护）

仓库页顶部的「Lv90 养成估算条」仅基于《无期迷途》狂级（S 级）禁闭者 1 级→90 级突破及升级的**固定通用货币经验消耗公式**（约 `2,000,000` 狄斯币 / `2,400,000` 狂厄精粹 ≈ 1 名），**不依赖角色材料映射表**，因此新角色上线时无需同步任何养成数据即可自动给出储备参考。
